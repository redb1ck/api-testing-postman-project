

API Testing Project — Postman


 Описание проекта

Учебный проект по тестированию REST API с использованием Postman.

В рамках проекта выполнена проверка основных HTTP-методов:
GET, POST, PUT, DELETE.

Подготовлена тестовая документация:
API Test Cases, Test Report, Postman Collection и результаты выполнения запросов.


 Цель проекта

Получение практического опыта в тестировании API:

- создание и отправка HTTP-запросов;
- проверка статус-кодов ответов;
- проверка структуры JSON;
- написание автоматических проверок в Postman;
- подготовка тестовой документации.

## Выполненные проверки


GET запросы

Проверка получения списка объектов.

Проверки:
- статус ответа 200 OK;
- наличие данных в ответе.


GET User By ID

Проверка получения пользователя по идентификатору.

Проверки:
- статус ответа 200 OK;
- наличие ID пользователя;
- наличие email.


POST Create Post

Проверка создания нового объекта.

Проверки:
- статус ответа 201 Created;
- корректность переданных данных.


PUT Update Post

Проверка обновления существующего объекта.

Проверки:
- статус ответа 200 OK;
- обновление данных.


DELETE Post

Проверка удаления объекта.

Проверки:
- статус ответа 200 OK;
- корректный ответ сервера.
